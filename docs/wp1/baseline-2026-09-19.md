## Characterization gaps closed at Gate 0

Behaviours WP1 touches that had no behavioural test on the base. Each now has
a characterization test (observable inputs/outputs/env/persisted state only)
in `tests/wp1/claude-characterization.test.ts` (C1, C5–C8) and
`tests/wp1/codex-characterization.test.ts` (C2–C4, C9). Eight source mutants
(`scripts/wp1/mutants.mjs`, re-runnable, in-memory restore) were applied one
at a time and each turned the relevant tests red before the tests were
accepted (withProfileHome also setting `CLAUDE_CONFIG_DIR`;
clobber-proofing removed; the delete handler's post-clear in-use check
removed; api-key mode not requiring a key; git/npm config pins dropped; PATH
dedupe removed; chatgpt/device dispatch swapped; the delete id guard removed).
