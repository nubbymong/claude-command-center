## 2026-10-06 -- WP2 PR 4: Electron 44 (#621), its ADR-009 round 1 and fix pass 10

**What.** Electron 43.7.1 to 44.5.1 (b84d9db3; supersedes #621), with paste
moved to Electron 44's promise-based clipboard API, a client-certificate rule
for main-process requests (b9e5d9fb: a request with no webContents presents
no certificate), a macOS 13 floor in the updater (1aa0a540) and a pin that
canvas content is refused every permission name Electron 44 declares
(e8317ceb).

**ADR-009 round 1 (three lenses: clipboard and paths, injection and the
certificate rule, updater and platform): FINDINGS, 1 major and minors, all
answered in fix pass 10.**
- 50972cb7: a Mac on an earlier version is never offered a release that
  needs macOS 13. The updater in 2.1.0 to 2.1.1-beta.1 matches any .dmg named
  `ClaudeCommandCenter-*` or `AI-Code-Conductor-*` and has no floor, so each
  Mac download that needs macOS 13 is named
  `AICodeConductor-<version>-macos13.dmg`, which it never matches; it is
  offered nothing, not an older release. This updater matches both names
  and takes the floor a name declares. The floors live in
  `resources/macos-release-floors.json`, read by the updater and the release
  gate, which refuses a cut whose Electron needs a newer macOS than its tag's
  floor (a bare `-beta` tag carries its final version's floor). An unreadable
  macOS version counts as the running build's own floor. Checksum and
  signature verification are unchanged.
- 7c5d5a31: a file copied from `\\localhost\<share>` pastes; a path on the
  `pipe`, `mailslot` or `IPC$` share of any server is never opened; Electron
  44 never offers FileNameW, so its fallback is gone; a copied image that is
  gone is no image.
- 0bfcfb6c: the install uses the Windows prebuilds of node-pty and
  better-sqlite3, as CI and the release build do (no Visual Studio
  Spectre-mitigated libraries needed); `npm run package` keeps the installed
  native binaries (`--config.npmRebuild=false`, as release.yml does).
26 mutants over the updater, the gate and the paste path rules: 26 red.
