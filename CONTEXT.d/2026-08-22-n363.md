## 2026-08-22 -- #363 "Ungrouped" header over the loose running sessions

### What changed

- `components/sidebar/UngroupedSessionsHeader.tsx` (new): the "Ungrouped"
  pseudo-group heading. It is `SessionGroupHeader` with fixed wording
  (`Collapse/Expand ungrouped sessions`, `Close all ungrouped sessions`) and
  `data-testid="ungrouped-sessions-header"`, so it looks exactly like a group
  heading -- triangle, name, hover-revealed close-all.
- `components/sidebar/SessionGroupHeader.tsx`: takes `name: string` instead of
  a `ConfigGroup`, plus optional wording overrides and a `testId`. The two
  call sites in `Sidebar.tsx` now pass `group.name`. Also gained
  `aria-expanded` on the toggle.
- `components/Sidebar.tsx`: one new piece of state,
  `ungroupedSessionsCollapsed: Record<string, boolean>` keyed by section id
  (`''` = the unsectioned tail), sitting next to `sessionGroupCollapsed` and
  living the same way (for the life of the window -- none of the session-list
  collapse state is persisted to disk today, so "persists like the others"
  means exactly that).
  - Inside a section: the loose sessions get the header only when that
    section also has at least one group with a running session.
  - The unsectioned tail: gets the header only when something organised sits
    above it -- a rendered section or an unsectioned group -- the same rule as
    the `loose-configs-divider` in the config panel.
  - When the header is not shown the loose rows render bare, exactly as
    before, and the collapse state is ignored (you cannot "lose" sessions
    behind a header that is not there).

### Why

Loose running sessions rendered bare under the last group header, so they
read as that group's tail. Book item 55 / #363. Configs already had a
divider for the same problem; sessions now get a real header because the
owner asked for collapse + close-all, which a divider cannot carry.

### How verified

- `tests/unit/renderer/sidebar-ungrouped-sessions-header.test.ts` (7 cases):
  header present with one group + two loose sessions, and ordered
  group-header < ungrouped-header < loose rows; absent when every session is
  loose (even with an empty group defined); absent when every session is
  grouped; collapse/expand hides only the loose rows and keeps the header;
  close-all kills/removes only the loose sessions; same treatment inside a
  section (only the section that has a group gets one, and collapsing it
  hides only that section's loose rows); a section above the unsectioned
  tail is enough to show the tail's header. Proven red on the old code
  (5 of 7 fail; the two "absent" cases pass either way).

  passed, 15 skipped. `npm run typecheck`: clean.
